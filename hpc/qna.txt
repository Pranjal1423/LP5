
# 🔹 What is OpenMP?

OpenMP is an API used for **parallel programming** in C/C++.

It allows multiple threads (CPU cores) to work simultaneously.

You enabled OpenMP using:

```bash
g++ -fopenmp bubble.cpp -o bubble
```

# 🔹 Parallel Bubble Sort Function

```cpp
void parallel_bubble_sort(vector<int>& arr)
```

This function sorts the array using:

## Odd-Even Transposition Sort

This is a parallel version of bubble sort.

Normal bubble sort cannot be fully parallelized because swaps depend on previous swaps.

So we divide sorting into:

* Even Phase
* Odd Phase

---

# 🔹 Outer Loop

```cpp
for (int phase = 0; phase < n; phase++)
```

The algorithm runs `n` phases.

Each phase performs comparisons in parallel.

---

# 🔹 Even Phase

```cpp
if (phase % 2 == 0)
```

In even phase:

Compare:

```text
(0,1), (2,3), (4,5)
```

Code:

```cpp
#pragma omp parallel for
for (int i = 0; i < n - 1; i += 2)
```

### Meaning

`#pragma omp parallel for`

→ OpenMP distributes loop iterations among multiple threads.

Each thread handles different comparisons simultaneously.

Example:

| Thread | Comparison      |
| ------ | --------------- |
| T1     | arr[0] & arr[1] |
| T2     | arr[2] & arr[3] |
| T3     | arr[4] & arr[5] |

---

# 🔹 Swap Condition

```cpp
if (arr[i] > arr[i + 1]) {
    swap(arr[i], arr[i + 1]);
}
```

If left element is larger, swap them.

---

# 🔹 Odd Phase

```cpp
else
```

In odd phase:

Compare:

```text
(1,2), (3,4), (5,6)
```

Code:

```cpp
#pragma omp parallel for
for (int i = 1; i < n - 1; i += 2)
```

---

# 🔹 Why Odd-Even Works

Alternating even and odd comparisons gradually pushes larger elements toward the end.

It behaves similarly to bubble sort but supports parallel execution safely.

# 🔹 Sequential Bubble Sort

```cpp
void sequential_bubble_sort(vector<int>& arr)
```

This is the normal bubble sort.

---

## Outer Loop

```cpp
for (int i = 0; i < n - 1; i++)
```

Controls number of passes.

---

## Inner Loop

```cpp
for (int j = 0; j < n - i - 1; j++)
```

Compares adjacent elements.

---

## Swap

```cpp
if (arr[j] > arr[j + 1]) {
    swap(arr[j], arr[j + 1]);
}
```

# 🔹 Important OpenMP Directive

## `#pragma omp parallel for`

This is the core of parallelization.

It tells compiler:

> "Split loop iterations among multiple threads."

Without it:

* Program runs sequentially.

With it:

* Multiple cores execute simultaneously.

---

# 🔹 Time Complexity

## Sequential Bubble Sort

Worst Case:

[
O(n^2)
]

---

## Parallel Bubble Sort

Still approximately:

[
O(n^2)
]

But execution becomes faster because work is distributed across threads.

---

# 🔹 Advantages of Parallel Bubble Sort

✅ Uses multiple CPU cores
✅ Faster for large datasets
✅ Demonstrates parallel programming concepts
✅ Simple OpenMP implementation

---

# 🔹 Limitations

❌ Bubble sort is inherently inefficient
❌ Parallel overhead can reduce benefit for small arrays
❌ Merge Sort or Quick Sort are better for real-world usage

---

# 🔹 Why Merge Sort is Better for Parallelism

Merge sort divides data recursively.

Different halves can be sorted independently.

So parallel merge sort scales much better than parallel bubble sort.

Time complexity:

O(n\log n)

while bubble sort is:

O(n^2)
